개인정보 처리방침 (초안)

이 문서는 초안이며 법률 검토 전입니다. 운영자 정보·연락처·보관기간의 [확인 필요] 항목은 확정 후 공개됩니다.

1. 수집·저장 항목

로그인 계정 정보(이메일, 이름, 로그인 제공자, 계정 식별자), 입력한 기업·제품·조건 정보, 생성된 후보·보고서·출처, 이메일 초안, 실행 기록(제공자·모델·소요시간·상태), 후보별 피드백(도움이 됨/맞지 않음/이미 아는 회사/연락함). AI 제공자 API 키는 저장하지 않습니다.

2. 이용 목적

파트너 매칭 품질 개선(후보 선정·점수 기준 분석), 서비스 오류 분석.

3. 저장 위치

Google Firebase Firestore (서울, asia-northeast3).

4. 보관 기간

[확인 필요: 운영자 확정] 삭제 요청 시 또는 보관기간 경과 시까지.

5. 삭제 요청

로그인 후 /app 하단 “내 기록 삭제”로 본인의 실행 기록·피드백·계정 기록을 직접 삭제할 수 있습니다.

6. 제3자 처리

입력 정보는 사용자가 선택한 AI 제공자(OpenAI 또는 Anthropic)에게 사용자 본인의 API 키로 전송됩니다. 저장소는 Google Firebase입니다.
