개인정보 처리방침 (초안)

베타 서비스용 초안이며 법률 검토 전입니다. 정식 출시 전에 운영자 정보와 연락 창구를 확정해 개정합니다.

1. 수집·저장 항목

로그인 계정 정보(이메일, 이름, 로그인 제공자, 계정 식별자), 입력한 기업·제품·조건 정보, 생성된 후보·보고서·출처, 이메일 초안, 실행 기록(제공자·모델·소요시간·상태), 후보별 피드백(도움이 됨/맞지 않음/이미 아는 회사/연락함). AI 제공자 API 키는 저장하거나 기록하지 않습니다. 다만 실행 중에는 입력 정보와 키가 PartnerFit 중계 서버(Vercel 서버리스 함수)를 거쳐 선택한 AI 제공자(OpenAI 또는 Anthropic)로 전달됩니다. 중계 서버는 로그인 확인과 허용된 주소로의 전달만 하며 내용을 따로 저장하지 않습니다(호스팅 사업자의 기본 접속 기록 여부는 확인 필요).

2. 이용 목적

파트너 매칭 품질 개선(후보 선정·점수 기준 분석), 서비스 오류 분석.

3. 저장 위치

Google Firebase Firestore (서울, asia-northeast3).

4. 보관 기간

베타 기간 동안, 그리고 사용자가 직접 삭제할 때까지 보관합니다. 베타 종료 시 보관기간을 정해 다시 공지합니다.

5. 삭제 요청

로그인 후 /app 하단 “내 기록 삭제”로 본인의 실행 기록·피드백·계정 기록을 직접 삭제할 수 있습니다.

6. 제3자 처리

입력 정보는 사용자가 선택한 AI 제공자(OpenAI 또는 Anthropic)에게 사용자 본인의 API 키로 전송됩니다. 저장소는 Google Firebase입니다.

7. 운영자·문의

운영자: PartnerFit 운영자(베타). 베타 기간에는 별도 연락처를 공개하지 않으며, 삭제는 /app의 “내 기록 삭제”로 직접 처리합니다. 정식 출시 시 문의 창구를 공개합니다.
